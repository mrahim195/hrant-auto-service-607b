# Hrant Auto Service

Production website for **Hrant Auto Service** — auto repair and brake shop in Pasadena, CA.

## Stack

- Next.js App Router
- TypeScript
- Framer Motion
- Nodemailer contact API

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

Configure SMTP in `.env.local` for the contact form.
